# CV and interview summary

## One-page CV entry

**IT Help Desk & Active Directory Home Lab** | Personal project

- Deployed a Windows Server 2025 Active Directory lab with 10 fictional user accounts, department OUs and a domain-joined Windows 11 workstation.
- Simulated and resolved L1 support tickets covering password resets, account lockouts, security-group membership, shared folder permissions and DNS troubleshooting.
- Configured SMB shares and NTFS permissions, validated authorized/unauthorized access and documented root causes and resolutions.

## 30-second interview explanation

"I built a small virtual company environment in VirtualBox using Windows Server 2025 and Windows 11. I created an Active Directory domain, added ten users in four departments, and joined the Windows client to the domain. Then I simulated common Help Desk tasks: resetting passwords, unlocking users, troubleshooting access to an HR folder, and diagnosing DNS problems. For example, I removed an HR employee from the security group that controlled folder access, investigated it with `whoami /groups`, and restored access. I documented the steps as support tickets on GitHub."

## Important wording

Call this a **personal hands-on lab** or **simulated support experience**. Do not describe it as paid production Help Desk employment.
